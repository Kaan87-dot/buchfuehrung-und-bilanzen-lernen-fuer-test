## ⚡ Der Machbarkeits-Check

**Versuch das jetzt sofort** (ohne nachzuschauen):

**Situation:** Du kaufst Waren für 1.000 € netto + 19% MwSt., zahlst bar.

**Wie lautet der Buchungssatz?**

<details>
<summary>👉 Klick hier für die Lösung</summary>

```
Wareneinkauf     1.000 €    an    Kasse    1.190 €
Vorsteuer 19%      190 €
```

**Erklärung:**
- Wareneinkauf = Aufwand → Soll
- Vorsteuer = Forderung → Soll
- Kasse = wird weniger → Haben

</details>

**Wenn du das verstehst → Du schaffst den Test!** 💪

---

## 🎓 Die 3 wichtigsten Regeln

### 1. Soll an Haben
```
Soll (links)  = Wo geht's hin? / Was wird mehr?
Haben (rechts) = Wo kommt's her? / Was wird weniger?
```

### 2. Vorsteuer nie vergessen!
```
Bei JEDEM Einkauf: + 19% MwSt.
Vorsteuer IMMER im Soll!
```

### 3. Die Abschlusskette
```
T-Konten → GuV → Eigenkapital → SBK
```

## 📊 Eselsbrücken (AUSWENDIG LERNEN!)

|--------------------|-------|-------------------------------|
| **Wareneinkauf**   | Soll  | "Aufwand kostet Geld"         |
| **Vorsteuer**      | Soll  | "Kriegen wir zurück"          |
| **Privatentnahmen** | Soll | "Geld raus = wie Aufwand"    |
| **Privateinlagen** | Haben | "Geld rein = wie Ertrag"      |
| **Alle Aufwände**  | Soll  | "Kosten = Soll"              |

## 🆘 Wenn du Probleme hast

### Problem: "Ich verstehe Soll/Haben nicht"
**Lösung:** Lies den Machbarkeits-Check in README_LERNPLAN.md nochmal. Denke: "Wo kommt's hin? → Soll"

### Problem: "Ich vergesse die Vorsteuer"
**Lösung:** Schreib auf einen Zettel: "19% IMMER dazu!" und klebe ihn neben deinen Monitor.

### Problem: "Die GuV verwirrt mich"
**Lösung:** Denke simpel: GuV = Sammlung aller Kosten. Das war's.

### Problem: "Abschlusskette zu kompliziert"
**Lösung:** Lerne auswendig: "T-Konten → GuV → EK → SBK". Mach Übung 2 in UEBUNGEN.md.
