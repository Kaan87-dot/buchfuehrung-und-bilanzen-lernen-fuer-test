## 💡 Wichtigste Regeln für die Prüfung

### Die 3 Grundregeln:

1. **Soll an Haben**
   - Soll (links) = Wo kommt's hin? / Was wird mehr?
   - Haben (rechts) = Wo kommt's her? / Was wird weniger?

2. **Vorsteuer nie vergessen!**
   - Bei jedem Einkauf: + 19% MwSt.
   - Vorsteuer IMMER im Soll!
   - **Bei Verkauf: + 19% USt. im Haben!**

3. **Die Abschlusskette kennen!**
   ```
   T-Konten → GuV → Eigenkapital → SBK
   ```

## ❓ Häufige Fragen

### Was ist der Unterschied zwischen Soll und Haben?
- **Soll:** Linke Seite des Kontos / Zugang bei Aktiva / Aufwand
- **Haben:** Rechte Seite des Kontos / Abgang bei Aktiva / Ertrag

### Warum steht Vorsteuer im Soll?
- Vorsteuer ist Geld, das du vom Finanzamt zurückbekommst
- Es ist eine Forderung → Aktiv → Soll

### Was kommt in die GuV?
- **Alle Aufwände** (Wareneinkauf, Miete, Zinsen, Abschreibungen)
- **Alle Erträge** (Umsatzerlöse - aber NICHT im Test!)

### Was ist der Unterschied zwischen EBK und SBK?
- **EBK (Eröffnungsbilanzkonto):** Start des Jahres
- **SBK (Schlussbilanzkonto):** Ende des Jahres / nach Abschluss
